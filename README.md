# Python Mini Projects

A collection of beginner-friendly Python projects created to practice programming fundamentals such as loops, conditionals, functions, user input, randomization, and basic problem-solving.

## Projects Included

### 1. Rock Paper Scissors
A command-line game where the user plays Rock, Paper, Scissors against the computer.

**Features**
- User vs Computer
- Random computer moves
- Winner determination
- Simple interactive gameplay

---

### 2. Password Generator
A customizable password generator that creates secure random passwords.

**Features**
- Custom password length
- Option to include letters
- Option to include numbers
- Option to include symbols

---

### 3. Number Guessing Game
The computer randomly selects a number, and the player tries to guess it with hints after every attempt.

**Features**
- Multiple difficulty levels
- "Too High" and "Too Low" hints
- Attempt counter

---

### 4. To-Do List
A simple command-line To-Do List application for managing daily tasks.

**Features**
- View tasks
- Add tasks
- Remove tasks
- Menu-driven interface

---

## How to Run

Clone the repository:

```bash
git clone https://github.com/yourusername/python-mini-projects.git
```

Navigate to the project folder:

```bash
cd python-mini-projects
```

Run any project:

```bash
python rock_paper_scissors.py
```

or

```bash
python password_generator.py
```

or

```bash
python number_guessing_game.py
```

or

```bash
python todo.py
```

These projects were built as part of my learning journey to strengthen my Python programming fundamentals through hands-on practice.
